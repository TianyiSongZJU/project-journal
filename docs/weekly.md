# 周记

在“回顾”的“月度”中，将鼠标移到某周，月份留白带底部会出现周记图标；已有内容的周会保留图标。悬停可查看周标题，没有标题时显示“写周记”。点击图标会轻微强调整周，并在右侧打开周记；点击某一天则返回当天记录。月历保留原有七列和日期格尺寸，不再设置独立周记入口。右侧箭头可以切换前后周。每周从周一至周日，跨年按 ISO 周编号显示。

每周包含标题、可勾选的目标和 Markdown 手记。标题会显示在左侧图标的悬停提示中。目标与项目无关，不会产生项目时间记录；页面投入摘要统计这一周全部项目已经记录的时间，不受回顾页的项目筛选影响，估算部分会标明。

编辑会自动保存。切换周、切换页面和关闭窗口前会先保存草稿；保存失败时留在当前周，保留输入并显示提示。导出全部数据也包含尚未保存的周记草稿。周记支持现有的撤销、重做、历史恢复、备份和导入导出。

只是查看一个空白周不会创建文件。填写后，每周单独保存在数据目录的 weekly/YYYY-MM-DD.json（旧目录布局为“周记/YYYY-MM-DD.json”），不按项目归属；历史版本继续使用已有的内容引用机制。

本功能随源码和本机构建更新。使用多设备同步时，各设备应使用支持周记的版本。
