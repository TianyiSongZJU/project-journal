# 项目手记 2.1.0 · 首个公开版本

本地优先的项目笔记、时间记录与工作回顾工具，支持 macOS 与 Windows。

- 项目/分组、总体笔记、每日记录、Markdown 预览与截止节点。
- 年/月热力图、项目时间分布、每日总投入与 15 分钟时间线。
- 可选前台活动、文件变化与需人工确认的建议区间，支持多设备线索对照。
- 本地分文件数据、历史恢复、同步副本提示、资料夹重新定位和显示偏好恢复。
- 中英文 README、五张虚构示例截图、隔离演示生成器、开发/隐私/贡献说明。
- MIT 开源许可及完整第三方声明；发行包不含个人笔记、活动记录或本机绑定。

## 下载

- macOS 13+（Apple Silicon / Intel）：project-journal-macos-universal.zip
- Windows x64（需要 WebView2 Runtime）：project-journal-windows-x64.zip
- SHA256SUMS.txt 用于核对下载文件完整性。

请完整解压到长期使用、可写的目录。数据默认保存在应用旁 data/。更新时保留 data/ 与本机设置；新用户首次打开从空白数据开始。同步请传输完整 data/，不要只传主 JSON。

Mac 应用为临时签名，尚未 Apple 公证；Windows 程序没有付费代码签名。系统可能需要手动确认可信来源。Mac 通用包已构建并签名验证；Windows 为交叉构建，欢迎报告实际设备问题。

自动采集是辅助线索，不是准确工时。建议需要人工核对；数据目前不加密。使用与同步说明请先看仓库 README。
