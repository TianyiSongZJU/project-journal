# 数据与隐私

项目手记是本地桌面软件。无需账号；当前应用没有自建云服务、内置遥测或远程 AI 分析。界面通过仅监听本机回环地址的后端读写数据；这不是可直接向公网开放的服务器产品。

## 保存哪些内容

- 你填写的项目、分组、总体笔记、每日备注、截止节点、投入时长及时间段。
- 开启前台活动后，采集范围随系统权限而变化，包括应用名称、部分窗口标题或文档关联，以及按时间桶汇总的活动量。后台线索不是对工作内容的准确认定。
- 开启文件观察并绑定资料夹后，保存相关文件名、相对/本机路径、创建/修改时间和变化元数据。本流程不读取文档正文；历史文件日期核对只生成待确认线索，不能还原准确工时。
- 每台设备有独立的本机设置，包括资料夹绑定与采集开关。显示位置和界面偏好也会本地保存。
- Mac 启动诊断保留耗时、启动来源等信息，不保存笔记、项目名称或窗口标题。

当前应用不采集屏幕截图、键盘输入内容或音视频。闲置确认后会回溯扣除相应无操作时间，但不能由此判断没有键鼠操作时是否仍在工作。

## 数据存在哪里

业务数据默认位于应用旁的 data/。笔记按项目、时长按月份、活动按设备和月份保存；主 JSON 包含项目、设置与索引。history-content/ 与 backups/ 用于历史恢复和保护。

本机配置通过系统配置目录、Mac 同级 local/macos/、--auto-home 或 JOURNAL_AUTOMATION_HOME 决定，具体取决于启动方式。不要将这些绝对路径直接覆盖到另一台电脑。

数据文件目前没有加密。能读取这些文件的本机用户、备份工具和你选择的同步服务，也可能读取其中内容。

## 同步与分享

应用不负责把数据上传网盘。你选择同步工具后，其隐私条款与访问控制决定同步后的处理方式。请同步完整 data/，包括隐藏标记和历史内容；不要只传主 JSON，也不要在同步未完成时反复覆盖。

不要在公开 Issue、截图、录屏或 Git 提交里包含真实项目名、笔记、活动标题和资料夹路径。仓库自带示例均为虚构，不含真实绑定。

## 关闭与删除

可以在记录设置中关闭采集、取消绑定；关闭采集并不自动删除已经保存的线索。完全退出应用后停止其后台记录。

需要彻底删除本地数据时，先退出应用、停止各设备编辑和同步，确认备份，再删除对应数据及历史/备份文件。本机设置和外部同步服务中的副本需分别处理；只删除某条当前记录，不代表历史与备份中的副本也立即消失。

当前保护机制不能保证任意同步服务下的实时协作或无损冲突合并。独立备份仍然必要。涉及安全问题请参照仓库 SECURITY.md。
