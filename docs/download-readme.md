# 项目手记 · Project Journal

完整安装、截图和使用说明：https://github.com/TianyiSongZJU/project-journal#readme

macOS：完整解压到长期使用、可写的文件夹，打开 项目手记.app。要求 macOS 13+，支持 Apple Silicon 与 Intel。应用尚未 Apple 公证；如系统拦截，请核对下载来源后在“隐私与安全性”中按提示允许。

Windows：完整解压，双击 项目手记-Windows.exe，保留同级 licenses/。需要 Windows x64 与 WebView2 Runtime：https://developer.microsoft.com/microsoft-edge/webview2/

首次运行会在应用旁建立 data/。更新时保留原 data/ 和本机设置，不要用示例数据覆盖。跨设备同步整个 data/（包括隐藏文件和历史/备份），资料文件与本机资料夹绑定分别处理。请保留独立备份，避免同步尚未完成时交替编辑。

Open 项目手记.app (macOS 13+, universal) or 项目手记-Windows.exe (Windows x64, WebView2 required). Keep the included licenses. Local data is stored in a sibling data/ directory. Preserve your data and device settings when updating. Sync the complete data/ folder with your own sync tool, and keep independent backups.

No personal data is bundled. The app starts empty. Monitoring is optional; suggestions require your review. Local files are not encrypted. macOS uses ad-hoc signing, and Windows has no paid signing certificate. Verify the download source before approving an OS prompt.
