# 项目手记 2.2.0 · 时段回顾与桌面体验更新

这次更新加入跨日期的时段回顾，并同步 Mac 与 Windows 的近期改进。

## 新增与改进

- **时段回顾：** 在“回顾 → 时段”按日期对照已确认的时间段，固定显示一周、两周或一个月。起止日期联动，箭头与滚动逐日移动，“今天”按钮将截止日期设回今天。
- **工作习惯对照：** 默认查看 08:00—24:00，也可切换全天；支持项目筛选、分项目配色、周末区分、每日项目分布悬浮卡片和点击展开当日记录。
- **时段日均图：** 各 15 分钟区间按所选日期计算日均投入，纵轴自适应最大值；支持项目堆叠和图例悬浮突出。没有起止时间的记录单独列出，不推断发生时段。
- **桌面布局：** 窄面板通过菜单切换当日记录与总体笔记；Mac 顶栏固定并以同色渐隐背景衔接，滚动时不再与标题重叠。宽窄面板、日期、选中状态和文字对齐有所调整。
- **Windows：** 加入原生浮雕方块启动过渡，支持减少动画设置；使用 `--background` 参数可只启动托盘与后台记录，托盘重开窗口时使用较短过渡。
- **文档与示例：** 更新中英文 README、时段回顾截图及可复现的虚构演示数据。

## 下载与更新

- macOS 13+（Apple Silicon / Intel 通用）：`project-journal-macos-universal.zip`
- Windows x64（需要 WebView2 Runtime）：`project-journal-windows-x64.zip`
- `SHA256SUMS.txt` 用于核对 ZIP 文件完整性。

请完整解压到长期使用、可写的文件夹。更新前先退出旧版；保留原来的完整 `data/` 和本机设置，只替换应用及随附的许可文件。不要用新解压的空白目录覆盖自己的数据。发布包不含个人记录、本机配置或演示数据，新用户首次运行从空白项目开始。

Mac 应用使用临时签名，尚未经过 Apple 公证。Windows 程序没有付费代码签名，需要 Microsoft WebView2 Runtime。Mac 通用包已完成构建与签名验证；Windows 已完成交叉构建及界面测试，本次未在 Windows 实机验证原生窗口动画。

活动线索仍需人工核对，未确认的建议不会计入项目时长。详细使用、隐私与同步说明见仓库 README。
