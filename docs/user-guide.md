# 项目手记 · V2.0.2

本地项目时间手记，支持 Mac 和 Windows，数据可随坚果云文件夹同步。

## 打开与升级

- Mac：双击“进度”文件夹内的“项目手记.app”，支持 Apple Silicon、Intel，要求 macOS 13 或更新版本。
- Windows：双击同目录的“项目手记-Windows.exe”，适用于 64 位 Windows 10/11；首次使用可能需要安装微软 WebView2 Runtime。
- 数据继续保存在“项目手记/数据”，升级沿用已有记录。V1 启动程序已保存在“项目手记/归档/V1.0.3-升级前”。
- 如果升级时软件仍然开着，请先从软件菜单退出，再重新打开。
- 当前 Mac 版为本地签名，尚未经过 Apple 公证。Windows 版已交叉编译，尚未在 Windows 真机上验证。

## 活动时间线

点击顶部“回顾 / 项目 / 记录”中的“记录”，在“记录设置”中绑定项目资料夹并选择需要检测的文件后缀。文件监听和前台辅助分别开启，前台辅助默认关闭。

每天默认展示 08:00–24:00，勾选“显示全天”可查看凌晨时段。每天只有一条总时间线，跨项目线索一起展示：左侧按 15 分钟显示应用时间占比，圆点表示聚合后的文件修改记录；右侧是你划定的投入时间。线索本身不能勾选，不自动产生工时。

1. 在右侧按住并上下拖拽，以 15 分钟吸附，可以划多段。鼠标旁实时显示起止时间、时长和项目；向上拖也支持。
2. 第一次可以先划时间，再在下方分配项目；尚未分配的选区也会自动保存。选择项目后，新选区会沿用该项目；顶部“接下来记给”可以切换或清空。
3. 单击已有选区后，拖动上下边缘调整；下方也能精确选择起止时间、改项目或删除。边缘聚焦后方向键每次调整 15 分钟。Esc 取消当前拖拽。
4. 选区之间不允许重叠；遇到已有选区，鼠标提示冲突，松开后保留原记录。前台/文件线索的重叠不影响你自己选择的时间，也不会重复生成时长。
5. 选区自动保存后仍不改变项目记录。点击“计入项目”才按项目更新当天时长。中午计入后晚上可以继续加段、缩短、删除、改归属；只结算与上次计入的差额，重复点击不会再加一遍。
6. 已有手动时长和笔记保留；已有五档按已配置的估算小时作为基础，未配置时会提示。旧手动时长没有起止时间，无法自动判断它是否和新选区重复，计入前请自行核对。
7. 切换日期、关闭窗口或退出前会保存选区；重新打开后仍可调整。待分配的选区分配项目后再计入。撤销/重做同时恢复选区与对应时长。

应用占比显示该时间格内已观测到的应用用时分布；主要应用直接显示，小占比应用合并为“其他”。悬停只显示各应用累计分钟和百分比，不再列出细碎切换。它仍然只是回忆线索，不直接计时，也不表示整个 15 分钟都在工作。

同一时间格中，同一文件的多次修改合为一组并显示记录数；多个文件显示文件数与总记录数。悬停按文件汇总次数和首末时间，最多列出 12 个文件并提示剩余数量，长文件名不会堆叠到下一格。

### 桌面界面与多客户端展示

Mac 和 Windows 记录页默认将多端前台活动合并到同一活动区，悬浮色块可查看各客户端分别观测到的分钟数；各端重叠观测不能直接相加为工时。点击前台活动菜单中的“分端对比”可改为按客户端并排展示，再次点击恢复合并；对比时点击设备名可快速只看这一端。前台活动菜单支持多选设备和“显示全部”，选择同时筛选活动与文件线索，不改变时间建议、选区或项目工时，偏好仅保存在当前电脑。对比时设备较多或窗口较窄，可横向滚动，时间刻度与选区操作区保持可见。Windows 应用名称展示时省略 .exe 后缀，Mac 应用名保留原样。每格表示 15 分钟内的累计量，不表示精确起止位置。Mac 保留原生标题栏与字体。

Mac 和 Windows 时间线的前台活动区按同时出现的应用数量及名称长度确定宽度，文件区按项目轨道数及标题长度分配空间，不再拉伸前台色带填满空白。切换日期、筛选客户端或调整窗口时会重新排布，上下滚动时保持列宽稳定；空间不足时保留最低可读宽度并允许横向滚动。

Mac 和 Windows 界面将记录页的“分端对比”收进前台活动菜单，默认只保留日期工具栏和一行列标题。项目页的截止节点使用日期、标题、备注及状态分层的紧凑列表，新增入口位于标题右侧。日期详情将当前项目当天总时长放在项目名与笔记页签之间，悬浮查看时间线与其他已记明细，点击直接展开其他已记的小时、滑杆和五档编辑，自动保存时保持展开；切换项目或日期后关闭弹层并更新数值。项目节点直接显示在当日备注之前，支持查看已完成、新增、编辑和勾选完成，节点备注可悬浮查看。

Mac 和 Windows 回顾与记录共用选中日期：回顾选定日期后打开记录，时间线跟随；记录切换日期后返回回顾，相应日期被选中并定位。回顾中的“今天”同时定位并选中今天，退出多选状态；切换前先保存当前编辑。

Mac 和 Windows 当日备注的“已保存、清除备注、预览”统一位于标题行；清除备注需要确认，取消时保留原内容，确认时只清除备注并保留时长。底部不再显示清除按钮，备注区域延伸至统一的底部内边距；其他已记时间仍从项目总时长弹层中调整。

### 历史文件线索

记录设置中可展开“补齐以前的记录”，选择起始日期核对文件创建/修改日期。这些旧日期只作为文件节点，不倒推活动区间或工时；复制、同步、下载也可能改变文件日期。

### 前台应用辅助（可选）

默认关闭。开启后，软件观察前台应用、窗口标题和空闲状态，辅助判断项目及投入时间：

- 优先按文件路径、已知文件名、资料夹名称匹配项目；有歧义的活动留为“未归类”，由你选择项目。
- Mac 读取窗口标题需要你主动允许辅助功能访问；不授权时仍可使用文件监听。
- 无操作达到阈值后，回溯扣除从最后一次键鼠操作起的本次无操作时间，包括阈值前暂记的部分；不足阈值的短暂停留仍计入。按实际秒数回扣对应应用及 15 分钟格，重启后也能核对暂记片段。新规则适用于更新后的新采集，人工确认的选区和工时不自动修改。
- 阅读、思考时没有键鼠输入，也会被视为无操作。
- 不截屏、不读取文档正文、不记录输入内容、不运行模型，采集内容保存在本地。

### 后台与低耗电

- 文件变化由 macOS FSEvents 或 Windows ReadDirectoryChangesW 通知，不按固定间隔遍历整个资料夹。
- 新绑定、重新启动、唤醒恢复或系统报告事件遗漏时会核对文件元数据；历史全量核对需手动触发。
- 连续变化合并处理，写盘批量进行；没有变化时不持续写盘。
- 前台辅助关闭时没有计时采样；开启后约每分钟检查一次空闲状态，应用和窗口切换使用系统事件。
- 关闭主窗口会释放界面，Mac 菜单栏／Windows 托盘继续保留自动记录。需要停止时可暂停，或彻底退出软件。
- 不自动设置开机启动。完全退出后不会持续采集；下次启动只能根据文件日期核对遗漏，无法恢复所有中间活动。

## 日常记录与回顾

“记一笔”可填写精确小时，或选择“很短／短／中／长／很长”；输入小时与五档互斥，滑块也可选时间。每天每个项目保留一份投入和备注，笔记与记录会自动保存。底部“清除时间”“清除备注”各自独立；总体笔记没有清除按钮。

年度热力图可左右连续滚动，月度日历可上下连续滚动。颜色按精确小时加已配置的五档估算加深，五档对应小时可在设置中调整。月度“分项目”会按行展示当天各项目，项目名一行省略，点击即可查看修改；同一周七天等高。

今天有独立圆环和外缘强调，仍保留原投入颜色；多选使用不同的描边和勾选标记。点击“多选”后可以拖动选日期，也可用 Ctrl／⌘ 多选、Shift 连选。指定项目、操作、任务和时长后，点击“应用到所选日期”，核对后确认。时间刷已移除。

项目可自定义排序，也可按 DDL、创建时间或最近记录日期排序。截止节点支持备注、优先级和完成状态；项目也可标记完成并保留历史。

## 撤销、备份与同步

- 顶部撤销／重做与“操作历史”保留最近 5 分钟全部操作，至少保留最近 10 次操作。自动草稿确认或忽略后撤销，会重新回到待确认状态。
- 每次主数据修改前备份，保留最近 60 份；设置中可导出或恢复主数据。未确认的采集草稿在“data/自动记录”中，完整迁移请复制整个数据目录。
- 自动记录的资料夹路径属于本机，保存在系统应用配置目录中，不随坚果云混用。Mac 和 Windows 分别绑定自己的路径。
- 各电脑的草稿分别落盘，随数据目录同步。确认状态写入主数据，另一台电脑同步完成后可看到处理结果。
- 建议轮流使用两台电脑；切换前彻底退出并等待坚果云同步完成，再打开另一台。数据同步冲突时，软件拒绝覆盖并提示核对。

## 验证情况

Mac 原生窗口已验证关闭后继续收集文件活动、重新打开查看以及正常退出。自动测试覆盖文件去重与忽略、历史日期、空闲及跨日计时、草稿暂存、保留／替换旧时长、确认与忽略、撤销回队列、同步副本合并，以及 V1 核心操作回归。

低耗电样本见“V2验证记录.md”。短时 CPU 和读写测量不能代表真实电池续航，仍需后续日常使用观察。

## V2.0.1：双端去重与更清楚的设置

“待确认”使用右上角“记一笔”左侧的 inbox 图标，透明背景，红色圆形角标显示待确认的日期数，同一天有多个项目也只算一天。页面使用深绿概览与浅色卡片，空白状态会明确说明当前是否暂停。

- Mac 和 Windows 的资料夹绑定分别保存在各自电脑，不需要手选操作系统。两台电脑选择同一个项目，绑定相同层级的对应资料夹即可；每个项目仍可有多个绑定。
- 同步文件按项目、相对路径、修改时间和大小合并提示，不读取正文或计算文件内容哈希。复制后日期或目录层级发生变化的文件仍需人工核对。文件日期只生成草稿，不测量工时。
- 前台辅助新增实际时段范围。同一项目同一天，双端重叠时段只算一次；前后接续的时段保留。已确认的时段不会因另一台电脑稍后同步而再次计入。旧版只有累计数字的活动无法还原重叠，跨设备采用较大的累计值作为保守建议。
- 设置分为开启文件记录、绑定资料夹、选择文件类型三步。时长辅助是可选项，默认关闭；名称、忽略文件夹与诊断信息放在更多设置中。
- 省电优先时，开启“收集文件活动”即可，前台时长辅助可保持关闭。首次绑定和手动核对历史会遍历一次，之后使用系统通知；实际耗电仍取决于资料规模和修改频率。
- Mac 菜单栏与 Windows 托盘明确显示“已暂停”“监听中”或异常，并给出单独的暂停／继续操作。“待保存后开启”只表示设置改动，点击保存、收到系统确认后才显示监听中。

## V2.0.2：项目分组、搜索与已完成折叠

新建或编辑项目时，可以选择已有分组或输入新分组。项目页“管理分组”支持新建、重命名和移除；重命名会更新组内所有项目，移除只把项目转到“未分组”，不删除项目或记录。分组保存到共享主数据，支持同步和最近操作的撤销。

项目页、回顾项目筛选、当天记录、记一笔、批量修改、待确认草稿及资料夹绑定都支持按项目名或分组关键词搜索。多个关键词用空格分隔，例如“科研 论文”。已完成项目默认收起，搜索时会自动展示匹配结果，仍可手动折叠。项目列表按分组展示，点击分组标题可折叠或展开；搜索时自动展开匹配的组，清空搜索后恢复原折叠状态。选择框和项目详情显示分组标记；月历紧凑条目保留一行项目名，悬浮提示显示分组。

项目选择菜单限制高度并可滚动，不会因为项目多而无限展开；分组内仍遵循已有项目排序。月度分项目 DDL 的顶端圆点已移除，保留竖线和白色描边。

项目时间分布和截止节点展开后，标题后的小文字按钮“按分组”可切换为分组展示；两处设置分别记住。今天用阴影强调，保留时长底色，选中日期仍用棕色描边。

按分组的时间分布顶部提供分组总览：同一比例条显示各组占比，下方列出各组总时长与百分比，再展示项目明细。总时长包含已配置估算；待配置记录单独提示，不计入比例。项目搜索框右侧“按分组”可切换分组或平铺，已完成项目仍单独折叠。

时间分布的“按分组”按年度/月度分别保存到应用设置：年度初始开启，月度初始关闭。两者修改互不影响，重新打开应用仍保留。分组总览采用浅绿底，组名、突出显示的时长和占比紧凑排列。

操作历史采用时间与条数双重保留：最近 5 分钟内的操作全部保留，同时至少保留最近 10 次操作；时间范围内超过 10 次仍可撤销。新增修改时整理历史，不增加后台定时任务。年度今天用虚线边框，年度 DDL 用右下角三角标记；月度今天的白边加粗。截止节点展开后，标题旁可直接切换“显示已完成”。


## 简单 Markdown 笔记

总体笔记、当日备注、记录窗口、截止节点备注和待确认草稿都支持 Markdown。直接输入即可，没有格式工具栏；右上角小字“预览／编辑”切换显示，有内容时默认预览，空白时默认编辑；预览中的待办可以直接勾选。⌘/Ctrl+S 保存笔记，点击“预览”也会先保存再切换；保存失败时保留编辑内容。总体笔记的保存状态与“编辑／预览”位于标题同一行。

```markdown
# 一级标题
## 二级标题
### 三级标题
**加粗** 和 *斜体*
> 引用
- 无序列表
1. 有序列表
- [ ] 待办
- [x] 已完成
```

常用快捷键：⌘/Ctrl+B 加粗、⌘/Ctrl+I 斜体；⌘/Ctrl+Alt+1、2、3 设置标题；⌘/Ctrl+Shift+7 有序列表、8 无序列表、9 待办，⌘/Ctrl+Shift+. 引用。笔记仍以 Markdown 纯文本保存，旧笔记无需转换。

项目页按左侧 30%、右侧 70% 展示。左侧采用较深的暖灰绿背景，包含新建项目和管理分组；右侧为浅色项目详情。macOS 顶部中间的空白处与“项目手记”文字可拖动窗口。

## 文件线索规则

实时文件变化保留轻量时间点；每个文件每天最多保留 512 个时间点。初次扫描和历史核对不虚构保存过程。

记录设置中的文件线索关联间隔默认 15 分钟（可调 1–120 分钟）：同项目相邻修改节点在这个间隔内以细虚线关联，仍然只是线索。默认 30 秒内至少 12 个不同文件变化时标记可能复制／同步，节点会变淡；窗口可调 5–300 秒，数量可调 3–200，支持恢复默认。

这些规则只整理线索，不影响你划定的选区，也不自动增加工时。选区固定以 15 分钟为最小单位。后台不新增周期扫描或模型调用；只有打开时间线时刷新线索。

前台辅助新采集主要保存“日期、项目、应用及每 15 分钟累计秒数”的紧凑计数，不再归档每次窗口切换和标题。历史逐段记录仍可读取，并按相同方式汇总显示；不会自动删除旧采集文件。

“记录”页保留一个浅渐变日期工具栏，选区和右侧编辑栏使用纯色。左右面板等高，编辑栏中间独立滚动，底部计入按钮保持可见；较窄窗口则把编辑栏放到时间轴上方。项目选择菜单的高亮和勾选始终随当前项目更新。


## 日期详情与截止节点

日期右侧的“所有项目”是该日期全部项目的总投入，包含已计入时间线及其他已记时间，不随项目选择或日历项目筛选变化。项目时间栏的“当前项目”只统计当前选择的项目。

所选日期的全部截止节点常驻在日期下方，显示节点名、备注与所属项目，作为只读概览，不重复显示“今天截止”。点击年历日期或月历截止标记会直接定位到日期详情。

选定项目后，“项目节点”紧凑列出该项目的全部节点，包括所选日期的节点；点击名称可编辑，勾选可标为完成，也可添加节点。已完成节点默认收起，通过“显示已完成”文字按钮切换。上方当天跨项目概览保持只读。

## 应用名称与前台活动展示

“设置 → 应用名称合并”可编辑显示名称和对应的原始名称。默认提供微信、Edge、Chrome、Word、Excel、PowerPoint、Visual Studio Code、飞书、钉钉与腾讯会议等分组；匹配完整名称，忽略大小写与末尾 .exe，不会自动合并不同浏览器。保存后对历史时间线同样生效，并随数据同步。删除全部分组并保存可关闭名称合并；恢复默认分组后仍需点击保存。原始线索和项目归属规则不变。

时间线逐个 15 分钟区间判断主要应用，不再只展示全天前 3 个。每格保留使用最多的应用，以及占该格展示宽度至少 20% 的应用，其余短暂活动归入“其他”。相邻同应用区间连成块；小幅排名波动只在该应用确实有活动、前后相同且没有明显竞争应用时衔接。没有活动的区间不会补齐，明显切换会断开。横向宽度仍表示观测量，多设备同时出现不会简单相加为投入时长。

## 重新打开时恢复界面

软件会记住本机最后所在的回顾、项目、记录或设置页面，以及回顾年月、查看日期、当前项目和笔记标签、时间线的显示范围与滚动位置。正常关闭窗口或退出后重新打开，会恢复这些界面位置；失效的项目和日期会自动回退。界面偏好保存在本机设置旁的 view-state.json 中，不进入共享 data 目录，也不改动笔记和时长。

项目侧栏、项目筛选和各处项目选择器的“按分组”、分组折叠、显示已完成会分别记住；回顾和项目页的截止节点筛选、年视图及项目面板的展开状态、记录设置的资料夹分组和已完成筛选也会恢复。时间线的分端对比、客户端选择、建议区间、全天及可见时长一并保留。关闭前台与完全退出后都有效，不依赖浏览器缓存或本次启动的端口。搜索关键词、临时弹出的菜单和未提交的操作不作为显示偏好保存。

回顾标签会显示今天所有项目未完成截止节点的数量，无待办时隐藏。已完成节点不计数；项目筛选不影响这个数量，跨天会自动更新。


达到空闲阈值之前，暂记片段会额外保存必要的时间边界和已加秒数，确认操作或回扣后清理，防止重启和跨月漏扣。

### Windows 启动与后台运行

Windows 也会在打开窗口时显示浅绿色浮雕方块过渡。界面和本机查看位置恢复后，方块沿波次下降、淡出，背景从方块附近逐渐散开；不会人为增加固定的加载等待。系统启用“减少动画”时直接显示界面，过渡结束后不保留动画循环。

整个启动过渡由 Windows 原生层绘制，从窗口出现开始播放，不依赖 WebView2 准备好后才开始。网页只在内容与本机查看位置恢复后通知原生层退场；方块和背景扩散使用同一段连续动画。主窗口照常显示、接收消息，不依赖隐藏窗口等待首帧。

启动快捷方式的参数设为 `--background`，可在登录后只启动托盘与后台记录，不弹出主窗口；双击托盘图标或选择“打开项目手记”可恢复界面。直接打开程序仍显示窗口。软件不会自动为其他电脑添加登录启动项。
## 时段回顾

在“回顾”顶部切换到“时段”，按日期横向对比每天的工作时间。横轴默认 08:00—24:00，每格 15 分钟；点“全天”可查看 00:00—24:00。

固定显示一周（7 天）、两周（14 天）或一个月（30 天）。顶部同时显示起始与截止日期，修改其中任意一个，另一端会按显示天数自动调整。左右箭头每次移动一天；在日期格上上下滚动也逐日平移，滚动灵敏度较低，连续滚动仍可切换，始终保持相同的显示天数。窗口较矮时，日期与星期几一同间隔显示，悬浮到某行时补全该行日期；悬浮或键盘聚焦时间格仍能查看完整日期。展开当日详情后，图表会压缩到剩余宽度，完整显示所选时段；横轴刻度按空间等距减少，不需要左右拖动。

项目筛选位于图表外侧的右上角。开启“周末”后，周六和周日的整行背景改用浅暖色，各行底色内缩并保留间隙，项目色块不变；关闭即可恢复。这个开关随本机显示偏好保存。关闭“分项目”时统一使用绿色，开启后使用项目颜色。底部柱形按项目上下堆叠，占比最大的项目在底层，高度表示当前日期范围内每一天在该时段的平均投入，纵轴按当前数据自适应，虚线标注最大的日均时长；悬浮柱形可查看累计时长与日均值。右侧数字保留当前横轴内的累计时长。悬浮或聚焦下方项目名称，会突出上方该项目的色带，底部只显示该项目的柱形与累计时长，纵轴比例保持悬浮前的尺度，便于比较。

当天日期旁显示“今天”标识，密集视图也会保留。悬浮到任意日期行时，整行显示浅绿底、细绿描边与白色内高光，右侧全天时长加深放大；浮层展示全天已确认时间的项目分布、时长与占比，包含当前横轴未显示的凌晨时间；未指定时段的记录单独列出。

点击日期或时间格，可打开当天记录；单一项目的时间格会同时选中对应项目。侧栏可调整备注与其他已记时间，也可跳到“记录”页核对具体区间。

这里只汇总已确认计入的时间段，不包含待确认建议或尚未计入的选区。只有每日总时长、没有起止位置的记录单独列为“未指定时段”，不会被自动分配。空白表示没有已确认时间段，不能据此判断该时段没有工作。每日右侧是全天已确认时长，包括横轴未展示的凌晨时间。

日期窗口、配色方式、全天开关、所选日期及横向滚动位置作为本机显示偏好保存，不参与项目数据同步。这个视图不迁移或改写历史记录。


## Mac 菜单栏与每日时长

菜单栏只显示图标，点击后可查看今日总投入。口径与当日记录上方“所有项目”一致，包含已确认时间线及其他已记时间，已配置的估算也计入；待配置估算不计入，并在菜单中提示。保存后、打开菜单时以及后台每 30 秒刷新，跨日后按本机日期重新统计。菜单内分开展示今日时长、自动记录状态和打开／退出操作。

时段回顾右侧保留每天的具体时长，并用窄而浅的横向柱形比较每日全天已确认时长。柱长按当前日期与项目筛选范围缩放；没有已确认时间段的日子不显示柱形，仍不代表当天没有工作。悬浮整行时，对应柱形稍微加深。
